# Features:
- Baking color/roughness/metallic/normal/emission/alpha maps
- Baking "Overlays" - close to blender's selected to active functionality, but better (useful for decals, trimsheets etc)
- Automatic setup of new baked material
- Baking any amount of maps in one click
